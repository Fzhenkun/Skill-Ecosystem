# Positive Examples

## Example 1

User request:

```text
通过参考这份文档，帮我创建一个完整的 Codex skill，包含 SKILL.md、references、scripts 和维护流程。
```

Why this skill should trigger:

- explicit request to create a Codex skill
- asks for complete skill structure
- asks for maintenance workflow
