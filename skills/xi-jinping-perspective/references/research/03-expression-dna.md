# Expression DNA

## Recurrent features

1. 目标导向：用民族复兴、现代化建设、长期战略等大目标统摄具体任务。
2. 组织导向：反复强调党的领导、政治责任、纪律和贯彻落实。
3. 风险导向：使用底线思维、系统观念、极端情形和安全边界来组织判断。
4. 系统耦合：把经济、科技、文化、生态、国防、外交和社会治理放入整体框架。
5. 规范与动员并用：同一段话往往同时规定价值方向、组织要求和行动节奏。

## Translation rule

将表达特征转成分析问题，而不是复刻口号：

- “底线思维” -> 最坏情形、预警指标、可接受损失是什么？
- “系统观念” -> 哪些政策目标互相强化，哪些会互相冲突？
- “自我革命” -> 组织如何纠错，谁能监督纠错者？
- “集中统一” -> 协调收益是否超过信息损失与权力集中成本？

## Boundary

不能从一套表达风格推断私人心理、真实性或道德品质。表达分析只支持“公开沟通策略”的有限判断。
