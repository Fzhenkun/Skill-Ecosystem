# Negative Examples

## Example 1

```text
把这篇 Markdown 翻译成英文。
```

不应触发：这是翻译，不是 SMART 执行方案整理。

## Example 2

```text
把这篇文章发布到我的 Jekyll 博客。
```

不应单独触发：这是博客发布流程，应使用 `blog-post-publisher`。

## Example 3

```text
总结一下这篇文章的主要内容。
```

不应触发：这是普通摘要，没有执行计划、SMART 目标或进度复盘要求。

## Example 4

```text
修改原始 Markdown，把表格格式统一。
```

不应触发：这是原文编辑任务，不是生成独立执行指南。
