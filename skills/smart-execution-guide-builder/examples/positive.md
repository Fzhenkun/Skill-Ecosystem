# Positive Examples

## Example 1

用户请求：

```text
把 D:\projects\Personal_blog_website\docs\编程刷题 下的所有 md，参考 basic_know 里的 SMART 文档，整理成一个快速准备面试手撕的执行指南，原文不要动。
```

处理要点：

- 扫描目录下全部 Markdown；
- 读取参考文档并提取其 SMART 组织方式；
- 按算法题型和面试价值重新归类；
- 加入 7 天计划、单题流程、进度复盘表；
- 输出新文件，不改原文件。

## Example 2

用户请求：

```text
我有一批系统设计笔记，帮我整理成 14 天有重点的学习和模拟面试计划，要有每天的验收标准和复盘表。
```

处理要点：

- 根据系统设计领域组织主题；
- 用“能讲、能画、能权衡、能应对追问”定义完成标准；
- 生成阶段计划和周期复盘表；
- 不把指南写成单纯的章节摘要。

## Example 3

用户请求：

```text
基于上次生成的学习指南和这周的执行记录，帮我调整下周重点。
```

处理要点：

- 读取已有指南和执行记录；
- 根据完成度、重复错误和截止时间调整优先级；
- 保留原计划可追溯性；
- 输出修订版或增量复盘，不覆盖原始记录。
