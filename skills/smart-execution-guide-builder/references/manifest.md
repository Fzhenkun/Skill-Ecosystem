# Manifest

## Purpose

将本地 Markdown 材料转化为基于 SMART 的可执行指南，帮助用户明确先做什么、做到什么程度、如何记录进度以及何时调整重点。

## Inputs

- 一份参考指南或样例文档；
- 一个 Markdown 文件；
- 一个包含多个 Markdown 文件的目录；
- 用户额外提供的目标、截止时间、领域背景或能力基线。

## Outputs

- 一份新的 Markdown 指南；
- 主题与原始文件的覆盖索引；
- SMART 目标；
- 优先级与阶段计划；
- 执行进度表、复盘表、错题/问题表；
- 可验证的完成标准。

## Must Preserve

- 原始 Markdown 文件；
- 用户给出的绝对路径、文件名、URL、代码和题目编号；
- 用户明确指定的时间、范围和格式要求；
- 不能从材料中确认的事实，不得伪装成材料原文。

## Must Not Do

- 不把多份文档简单首尾拼接；
- 不用刷题数量或阅读篇数代替能力验收；
- 不默认修改原文；
- 不默认提交、发布或推送生成结果；
- 不把博客 Front Matter、图片下载或 Jekyll 流程混入本技能。
