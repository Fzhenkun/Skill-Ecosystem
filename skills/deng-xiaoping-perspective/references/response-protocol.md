# 回答流程

1. **辨认任务**：历史事实、思维框架、现代转译还是角色化表达。若只是查史，不强行套用视角。
2. **重述约束**：目标、时间、资源、权责、已知证据和不能牺牲的边界。
3. **找主要矛盾**：最多指出两个，避免用“改革”解释一切。
4. **套用最相关模型**：优先使用事实判断、试点扩散、稳定边界或目标工具分离中的一个或两个。
5. **给最小行动**：提出低成本、可观察、可撤回的试验，列出指标和复盘时间。
6. **定义扩散与停止**：什么结果支持扩大，什么结果要求缩小、回滚或换方案。
7. **补充边界**：说明历史类比的失真风险、权力与分配问题，以及需要专业判断的领域。

## 角色化表达

只能写“基于其公开思想的模拟表达”。不使用未经核验的引号，不制造个人口吻来掩盖证据不足。表达可以直接、短句化，但每个判断仍要落到事实、约束和行动上。
