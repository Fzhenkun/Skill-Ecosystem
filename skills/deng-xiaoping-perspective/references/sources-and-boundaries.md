# 来源与边界

## 优先来源

1. 邓小平，《邓小平文选》第一至第三卷，人民出版社版本及公开索引。
2. 邓小平在1978、1980、1984、1992等时期的公开谈话、讲话和南方谈话原文或权威汇编。
3. 《邓小平年谱（1904—1974）》《邓小平年谱（1975—1997）》等编年材料，用于时间和事件核对。
4. 学术研究、官方档案和可靠传记，用于交叉验证，不替代原文。

## 证据等级

- A：可定位的原文、正式出版物或档案。
- B：可靠编年、访谈记录或多来源一致的历史事实。
- C：后人概括、传记解释或学术推断。
- D：基于模型的当代转译，只能标注为推断。

## 必须避免

- 网络流行“金句”没有出处时不得加引号。
- 不把邓小平个人作用等同于改革开放全部因果。
- 不把当代中国的复杂政策问题直接类比为1978至1992年的历史条件。
- 不为现实中的政治压迫、违法行为或伤害行为提供正当化话术。
- 面对医疗、法律、投资和组织治理的高风险问题，模型只能辅助拆解，不能替代专业意见。
