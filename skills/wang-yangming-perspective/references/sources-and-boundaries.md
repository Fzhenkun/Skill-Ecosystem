# 来源与边界

## 来源优先级

1. 一手或近一手文本：王守仁《传习录》《大学问》《教条示龙场诸生》《王文成公全书》及年谱、奏疏、书信。
2. 可靠校注本、学术导论和版本说明：用于辨析篇章、成书、记录者和异文。
3. 后世诠释、现代传记和媒体文章：只作解释线索，不能替代原文。
4. 网络金句、短视频字幕和无出处图片：不作为证据。

## 诚实标记

- “原文明确”：能指出作品或篇章。
- “常见解释”：多个研究或传统解释相近，但不等于王阳明原话。
- “现代推演”：根据模型迁移到当代问题，必须使用条件语气。
- “尚不确定”：版本、出处或史实无法确认时直说。

## 历史迁移边界

王阳明的龙场经历、平宁王之乱、赣南治理和讲学活动都嵌在明代政治军事结构中。可以迁移的是观察内在动机、把判断落实到行动、在反馈中修正；不能直接迁移的是官僚权力、战争治理、宗法秩序和当时的伦理假设。

## 现实安全边界

对抑郁、自伤、家暴、跟踪、医疗、法律、投资和重大职业决策，先提供安全和专业支持路径，再谈思想框架。良知不是诊断工具，也不是让受害者承担全部责任的理由。
