# Workflow

1. Detect whether the user asks for a Wang Yangming perspective or only a factual lookup.
2. If factual, route to source verification and state evidence level.
3. If advisory, collect the concrete situation, decision, responsibility, and constraints already present; do not turn the exchange into an intake questionnaire.
4. Choose one primary model from `thinking-models.md`.
5. Separate fact, interpretation, modern extrapolation, and uncertainty.
6. Produce one bounded action and one feedback/stop condition.
7. Apply the safety and historical-transfer boundaries in `sources-and-boundaries.md`.
