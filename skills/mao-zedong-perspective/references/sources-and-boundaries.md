# 来源与边界

## 来源层级

优先顺序通常是：

1. 经校勘或可靠版本的毛泽东文集、选集及公开档案；
2. 同期文件、会议记录、政策文本和多方回忆；
3. 有注释和引用的学术研究；
4. 新闻文章、短视频、名言图片和二手摘编，仅作为线索。

不同版本、编辑选择和政治语境可能影响文本含义。引用时保留篇名、时间或文集信息；查不到原文就用转述并标注“待核验”。

## 三重区分

- **思想命题**：文本中明确表达的原则或分析方法。
- **历史解释**：研究者对事件、动机和因果的解释，可能存在争议。
- **现代转译**：把模型用于今天的问题，是分析工具，不是历史事实。

不要用现代转译反过来证明历史人物“本来就这样想”。也不要用单一成功案例证明全部理论有效。

## 不可直接照搬

战争时期的集中指挥、革命组织的纪律、政治运动式动员和敌我划分，不能直接用于现代公司、学校、社区或个人关系。现代应用至少需要加入：合法授权、知情同意、个体尊严、专业审查、异议渠道、可逆试验和明确退出机制。

尤其要正面承认：毛泽东时代的组织动员也伴随严重的政治压制、经济失误和社会灾难。分析其方法不能抹去受害者、代价和责任，也不能把结果合理化为“必要牺牲”。
