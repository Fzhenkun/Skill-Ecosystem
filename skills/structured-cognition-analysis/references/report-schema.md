# Report Schema / 报告中间结构

The JSON is an optional intermediate representation. The required user-facing artifact is Markdown generated by `scripts/render_report.py`.

```json
{
  "title": "Subject name",
  "subtitle": "optional framing",
  "language": "zh",
  "complexity": "complex",
  "scope": "One-sentence object, user need, and evidence boundary",
  "essence": "One-sentence essence",
  "context_map": {
    "scope": "in scope and non-goals",
    "components": ["..."],
    "actors": ["..."],
    "flows": ["input -> mechanism -> output"],
    "dependencies": ["..."],
    "lifecycle": ["..."],
    "failure_surface": ["..."]
  },
  "key_mechanisms": [
    {
      "name": "Mechanism",
      "chain": "condition/input -> mechanism -> state/effect -> output",
      "importance": "why this part was selected",
      "points": [
        {"text": "Specific claim", "type": "fact", "confidence": "high"}
      ]
    }
  ],
  "anomalies": [
    {
      "observation": "What looks irrational or broken",
      "evidence": ["source or inspection"],
      "historical_explanation": "confirmed cause or unknown",
      "hypotheses": ["plausible but unconfirmed explanation"],
      "current_constraint": "whether the old constraint still exists"
    }
  ],
  "boundaries": [
    {"text": "Specific applicability or failure condition", "type": "fact", "confidence": "high"}
  ],
  "verification": [
    {
      "check": "experiment, inspection, scenario, measurement, or falsifier",
      "expected": "observable result",
      "result": "observed result or pending",
      "limits": "what this check cannot prove"
    }
  ],
  "lenses": [
    {
      "name": "Assumptions / 基石假设",
      "summary": "Short conclusion",
      "points": [
        {"text": "Specific finding", "type": "inference", "confidence": "medium"}
      ]
    }
  ],
  "conclusion": {
    "stance": "Recommended stance",
    "risks": ["..."],
    "open_questions": ["..."]
  },
  "sources": ["optional references"]
}
```

## Field Rules / 字段规则

- `complexity` is `complex` or `simple`; it controls breadth and depth, not the workflow.
- `context_map` may be short for a simple subject. Do not fabricate components that do not exist.
- `key_mechanisms`, `anomalies`, `boundaries`, and `verification` are the primary report sections. They may be empty only with an explicit reason in the Markdown.
- `lenses` contains only useful lenses; it replaces the old requirement to force all eight dimensions.
- `type` is `fact`, `inference`, or `speculation`.
- `confidence` is `high`, `medium`, or `low`.
- User-provided names, quotes, numbers, paths, and identifiers must remain verbatim.
