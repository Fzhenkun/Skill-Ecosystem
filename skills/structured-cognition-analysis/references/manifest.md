# Manifest / 能力清单

## Purpose

Provide one evidence-disciplined cognition workflow that scales from a single mechanism to a multi-component system. The output explains the object in context, identifies causal mechanisms, follows surprising choices back to historical constraints when evidence permits, and verifies important claims through practice.

## Fixed Flow / 固定流程

1. 界定对象
2. 建立全局/上下文地图
3. 识别关键机制
4. 追溯反常点
5. 分析边界与代价
6. 用实践验证
7. 输出 Markdown

Complexity only changes map size, selection of critical parts, and depth of evidence. It does not change the flow.

## Capability Inventory / 能力清单

- Scope a subject and state evidence boundaries.
- Build a system map for complex subjects or a minimal context map for simple subjects.
- Explain mechanisms through causal chains rather than lists of terms.
- Surface hidden assumptions and principal contradictions.
- Investigate anomalous designs and distinguish historical evidence from hypotheses.
- Analyze applicability, failure modes, costs, alternatives, and trade-offs.
- Design small practical checks, reproductions, inspections, measurements, or falsifiers.
- Separate fact, inference, and speculation with confidence labels.
- Produce a readable Markdown report from an optional JSON intermediate.

## Eight Lenses / 八个分析透镜

These are questions applied inside the fixed flow, not a mandatory eight-section template:

| Lens | Core question |
| --- | --- |
| Assumptions | What must be true for this to work? |
| Principles | What causal mechanism explains it? |
| Goal | What outcome and metric does it serve? |
| Contradiction | What tension does it resolve, and what does it sacrifice? |
| Content | What are the concrete components and terms? |
| Means | How is it implemented or used? |
| Boundaries | When does it fail, and what does it cost? |
| Evolution and verification | Why is it shaped this way, and how can we test it? |

## Boundaries / 边界

Use for understanding, evaluating, dissecting, comparing, or critiquing a technology, method, product, system, project, policy, theory, decision, or non-trivial knowledge question.

Do not use for trivial facts, direct lookups, translation, or ordinary coding. For a small question, answer with the same flow at minimal scale rather than forcing a long report.

## Quality Bar / 质量标准

- The report states scope and context before local conclusions.
- Complex subjects include a usable system map and justify selected deep dives.
- Simple subjects remain concrete and do not contain padded sections.
- Surprising choices receive historical investigation or an explicit evidence gap.
- Important claims have a practical check or falsifiable prediction.
- Claims are labeled by type and confidence; sources are not invented.
- The final artifact is Markdown and is readable without the intermediate JSON.
