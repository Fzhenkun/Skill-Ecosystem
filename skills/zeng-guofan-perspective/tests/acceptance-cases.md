# 曾国藩视角 Skill 验收场景

## 触发场景

1. 用户说“用曾国藩的视角分析我该不该接这个管理岗位”。应触发人物视角分析，区分志向、能力、资源、责任与风险。
2. 用户说“团队执行力差，曾国藩会怎么带”。应触发组织与识人用人框架，输出选人、分工、训练、复盘和纪律机制。
3. 用户说“我总是拖延，曾国藩会怎么劝我”。应触发修身与日课框架，给出可记录、可复盘的小行动，不伪造曾国藩原话。

## 不触发场景

1. “曾国藩是哪一年出生的？”这是历史事实查询。
2. “帮我写一封普通商务邮件。”没有曾国藩相关意图。
3. “清末湘军的编制是什么？”这是史实研究，除非明确要求曾国藩式分析。

## 质量断言

- 事实、原文、后人概括和现代转译必须分层。
- 网络“曾国藩名言”不能自动当作曾国藩原话。
- 建议至少包含当前矛盾、可执行动作、复盘指标、停止条件和适用边界。
- 不把曾国藩的家长制、等级秩序或晚清政治处境直接当成现代组织规范。
