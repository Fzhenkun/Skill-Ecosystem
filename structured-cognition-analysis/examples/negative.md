# Negative Examples (should NOT trigger)

- "What's the capital of France?" (trivial fact)
- "Fix this null pointer bug." (ordinary coding)
- "Translate this paragraph." (no analysis needed)
- "Create a new skill for X." (use skill-lifecycle-engine)
- "Which color for this button, red or blue?" (trivial choice; over-analysis)

## Counter-example: rewriting user text

User says "分析 OKR 3.0 方案". Titling the report "OKR methodology" or translating the name is wrong; keep "OKR 3.0 方案" verbatim.
